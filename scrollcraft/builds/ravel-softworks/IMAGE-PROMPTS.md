# Image prompts

Generate by hand (Gemini app, AI Studio or any image tool) and save into
`assets/img/` with exactly these names. `.jpg`, `.png` or `.webp` all work. The
page finds each file automatically; a missing file keeps its drawn illustration.

| File | Where it appears | Aspect ratio |
|---|---|---|
| `software.jpg` | Services card: Custom software development | 16:9 |
| `team.jpg` | Services card: Software development outsourcing | 16:9 |
| `automation.jpg` | Services card: AI automation & agents | 16:9 |
| `ai.jpg` | Services card: AI implementation | 16:9 |
| `data.jpg` | Services card: Integrations & data | 16:9 |
| `cloud.jpg` | Services card: Cloud, DevOps & IT support | 16:9 |
| `why.jpg` | "We're new. That works in your favour." section | 4:5 (portrait) |

Keep each file under about 400 KB (roughly 1600px wide at 16:9, 1200px wide for
`why`). Reject any image with readable text, fake logos, garbled screens or
faces looking at the camera.
